# 💰 CodingCamp 28September26 — Expense & Budget Visualizer

A simple and responsive web application for tracking daily expenses, managing spending limits, and visualizing spending patterns by category.

Built as a project for **CodingCamp 28September26**.

---

## ✨ Features

### 💸 Expense Tracking
- Add daily expenses with:
  - Item name
  - Amount
  - Category
- Delete transactions
- Automatically calculate total spending
- Transaction data is saved in the browser using **Local Storage**

### 📊 Spending Visualization
- Visualize expenses by category using an interactive chart
- Automatically updates when transactions are added or deleted

### 🗂️ Category Management
- Default categories:
  - 🍔 Food
  - 🚗 Transport
  - 🎮 Fun
- Add custom expense categories

### 📅 Monthly Summary
- Filter transactions by month
- View spending summaries for the selected month

### ↕️ Transaction Sorting
Sort transactions by:
- Newest
- Oldest
- Highest amount
- Lowest amount
- Category

### 🎯 Spending Limit
- Set a monthly spending limit
- Track spending progress with a visual indicator
- Get a visual warning when spending exceeds the limit

### 🌙 Dark / Light Mode
- Switch between light and dark themes
- Theme preference is saved in the browser

---

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling and responsive layout
- **JavaScript (Vanilla JS)** — Application logic and interactivity
- **Chart.js** — Spending visualization
- **Local Storage API** — Client-side data persistence

No backend or framework is required.
